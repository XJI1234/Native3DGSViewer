# 兼容性调试经验

## Intel Arc / UMA

Windows 11 23H2 build 22631 的 Intel Arc 核显可报告约 128 MiB dedicated video memory 和约 19.2 GB shared system memory。不能据前者判定模型不适合加载，也不能据宿主 16 GB 或 32 GB 物理内存保证任意模型都可加载。通过 `D3D12_FEATURE_ARCHITECTURE1.UMA`（失败时回退旧查询）确定内存架构；UMA 的上传页计入 local 增量估算，non-local 查询不作为准入条件。保留 DXGI 动态预算的 80% 余量检查。预算拒绝应记录阶段、UMA、两段预算和用量及模型估算需求。

Intel Arc 报告 wave lane 范围 8-32，固定 wave32 SM6.6 变体在目标设备自检成功，SPZ 与 PLY 均加载并浏览流畅。驱动能力查询只表明支持范围，排序正确性仍需 GPU 读回自检。自检失败要回退 wave-agnostic 变体或停止渲染，不得渲染未验证的数据。

## 显示镜像与输入

奇数个模型轴镜像时，宿主水平镜像合成画面。`RenderTransform` 也会改变控件局部指针坐标；固定模式若从该控件读取拖动增量，鼠标方向会反转。输入增量应从未受镜像的父级坐标获取，再按正常相机命令转换。屏幕方向的输入约定与场景世界轴的镜像分别处理。

## 发布与诊断

正式版保留启动排序自检及 UMA 预算诊断。每次启动独立 JSON 行日志，记录系统与 GPU 能力、启动结果、场景成功/失败、设备恢复和退出；不记录完整模型路径或逐帧信息。日志优先写安装目录，失败时回退 `%LOCALAPPDATA%`，仅清理超过 30 天且符合程序文件名格式的旧日志。普通信息和错误由系统文件缓存，启动关键节点和正常关闭时刷新，避免错误风暴阻塞 UI。发布 SDK 时打包完整 `docs/`、GUI 宿主说明、公共契约、示例、运行时和许可证；解包后独立编译并运行消费示例验证可重定位性。
