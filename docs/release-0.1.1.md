# Native3DGS 0.1.1

## 更新

- Windows 11 23H2 / Intel Arc UMA 上，固定 wave32 排序自检通过，SPZ 与 PLY 模型成功加载并浏览。UMA 上传预算不再依赖 non-local 内存段；失败时记录 DXGI 预算、用量和估算需求。
- 修复 WinUI 查看器翻转 Y 后固定模式拖动方向反转：指针增量统一从未镜像的根布局坐标计算。
- 正式版保留启动 GPU 排序自检及 wave-agnostic 回退。设备移除和 GPU 超时不会触发不安全的重试。
- 日志记录启动硬件、着色器、场景结果与错误；安装目录不可写时回退到 `%LOCALAPPDATA%`，清理超过 30 天的程序日志，不记录模型完整路径或逐帧数据。
- SDK ZIP 包含完整开发规格、验证记录、GUI 宿主说明、示例、运行时文件及依赖许可。

## 验证

Release x64 构建、五组 CTest、独立解包并重定位的 SDK 消费测试、安装包隔离目录安装及真实 PLY 启动均通过。目标 Intel Arc 设备的 SPZ/PLY 加载与流畅浏览由用户日志和实测确认；本版 Y 翻转后的鼠标方向仍待该设备人工复核。

安装包未签名。Spark 等画质图像与完整性能门槛、AMD 及更多设备矩阵尚未验收。
