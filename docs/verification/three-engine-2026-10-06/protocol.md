# Three-engine continuous interaction protocol

Authorized 2026-10-06 after preview.3 publication. Measure Windows native SDK render-core host, Web SDK preview.3 defaults, and Spark 2.3.1 serially on this computer.

Select paired PLY/SPZ: shengyi (804,758 points), he (2,973,002), jiulonghu (22,480,361). The smaller changjin and larger-medium zhihuizhimen have no matching SPZ in the supplied corpus. Preserve full logical point counts, SH3 and default precision; disable Windows memory mitigation and Spark LoD. Use 1920×1080, 60° FOV, common native-fit initial world pose and the same 18-second wall-clock orbit/zoom/pan trajectory.

Each case: fresh process/profile, engine/device initialization outside load timer, source read through first complete GPU frame/present inside load timer; 5-second interaction warmup then 20-second sample. Repeat each case three times. Browser Web default auto/4 and adaptive; Spark defaults of the existing matched radial/full-point harness. Native uses public model-loader/renderer APIs and an actual HWND DirectComposition swapchain; no modification to Windows render algorithms or SDK contracts. Tick the host at 120 Hz to match this display/browser's observed rAF limit. This is an SDK host, not WinUI UI automation. Count accepted DXGI Presents separately from render calls, browser render submissions separately from input callbacks. Neither is physical scanout; avoid labeling GPU stage duration or fenced benchmark reciprocal as browsing FPS.

Main figure: one figure with two grouped-bar panels, six model/format groups × three engines: end-to-end full loading seconds and milliseconds per browsing frame (1000/FPS), median across independent repeats with min/max whiskers. Publish raw runs, source/model/binary hashes, FPS/1% low/count and protocol limits. Local disk and loopback URL loading include different host I/O costs; do not call either a pure decoder kernel comparison. Native default quality cutoffs differ from Web/Spark; full point/SH retained and the user has waived image-quality matching.

Stop or invalidate cases on count/SH mismatch, automatic mitigation, backend mismatch, source mismatch, hidden browser, device/console errors or incomplete timing. Resource failures must be reported, never converted into faster reduced-point measurements. GPU cases run serially. Record existing evidence separately from this new measured matrix.
