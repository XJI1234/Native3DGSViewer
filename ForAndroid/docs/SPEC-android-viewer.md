# Spec: android-viewer

## 目标与界面范围

提供面向手机和平板的原生离线 3DGS 查看器，证明 AAR 作为真实应用依赖可用。宿主仅调用 `android-bridge` Kotlin API，负责系统文件选择、SurfaceView、手势、可见进度/错误与应用生命周期；不直接触碰逐 splat 数据或 Vulkan 对象。首期不含编辑、导出、内置模型商城和远程 URL。

首屏是可用的空视口与打开文件命令，非宣传页。模型显示后有当前文件名、固定/自由模式切换、适配、重置、关闭和重新打开；加载时进度只显示可证实的阶段/字节，可取消。失败时显示简短、可行动的用户提示，保留旧模型。UI 文案不展示内部 shader、JNI 或预算实现细节；详细信息写本地诊断日志。

## 交互和生命周期

固定模式：单指拖动以屏幕方向旋转模型，双指移动平移、捏合缩放；屏幕轴镜像不能改变手势方向。自由模式：左侧虚拟摇杆作水平前后/左右移动，右侧拖动转向，升降用独立上下控件；按实际 `dt` 限幅，抬指、失焦、进入后台立即清零移动输入。适配和重置命令不改模型数据；屏幕旋转保留相机和模式。

Kotlin Android Views/Material 组件承载按钮、进度及状态，`SurfaceView` 为无卡片包围的主视口。手机竖屏以精简工具栏和可收起控制区避免遮挡模型；平板横屏保持更宽的工具区和大视口。所有按钮有无障碍标签，触控目标至少 48 dp，系统字体缩放/深浅色/屏幕内边距可用；错误、空状态与低性能警告不会盖住关键操作。只在 active Surface 有效时发送渲染尺寸；Activity 暂停/恢复和 `surfaceDestroyed` 正确 detach/rebind。

系统选择器使用 `ACTION_OPEN_DOCUMENT`，请求 PLY/SPZ 或可匹配的通用类型，最终仍由内容签名验证。显示名称来自 provider 的安全显示名，不把完整 URI 写入常规日志。当前模型只读，用户关闭或系统进程结束后不保留未经授权的访问。启动缺 Vulkan 能力时显示设备不支持及退出/重试入口，不能白屏或假报“内存不足”。

## 实现与验收

先用假 engine 快照实现空/加载/失败/Ready/恢复状态，再接真实 AAR；固定触控完成后加自由模式、手机/平板布局和生命周期。UI 仪器测试覆盖权限取消、无效文件、连续选文件、关闭、旋转、后台、恢复和无 Surface；固定模式左拖与镜像组合须方向一致。连接模拟器用于布局、选择器、Service 和状态测试；其实际 Vulkan 能力探针若失败，只验证不支持设备状态。最终图像和持续流畅性只能在 `arm64-v8a` 真机验收。
