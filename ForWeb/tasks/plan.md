# Web 引擎实施计划

2026-10-04。用户已授权依据系统设计实施、安装 WASM 工具链、测试指定本地模型、Spark 对比、调优、审查及接入文档。本目录能力图作为已接受的实施边界；不重复申请逐阶段权限。

先固定环境与模型 manifest，再完成解码 → GPU 排序/图像 → 生命周期 → 适配/包装 → 实测调优 → 审查及文档。新增源码均在 ForWeb；共享原生源码只编译复用，暂不改原生公开接口。首期以主线程短提交 + 解码 Worker 为基线，渲染 Worker 增强在基线验证后实现。

现实约束：输入集合存在 5.3 GB PLY；完整加载能力取 CPU policy/wasm32/WebGPU 实际 limits 的最小值。超限错误测试属于验收，不以降阶或抽样冒充成功。Spark 对比固定安装版 2.3.1（用户要求 SparkJS，当前稳定版），记录与早期 Spark2.1 基线的版本区别；同画质未对齐前不宣布胜出。

检查点每阶段保存实测证据，GPU 验证必须使用 RTX 3080 实际硬件 adapter。未覆盖浏览器/厂商标未测试。
