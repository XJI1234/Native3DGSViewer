release artifact, before the per-file hash assertions and ZIP validation succeed. If a source

[test · medium] These fingerprints are taken only after the browser run, so they do not establish
which files were actually tested. A source/dist edit during the run can be recorded as verified, and
production preview can test a stale dist while recording newer source hashes. The build recorder's
before/after check covers building, not this browser run. Snapshot inputs/outputs before starting
the server, validate production snapshots against the build manifest, and reject changes at the end
before writing successful evidence.

[test · medium] The preservation check compares only the red feature's centroid. Losing the
green/blue splats, changing their positions, or changing the red splat's size symmetrically still
passes, even though the evidence reports scene preservation/recovery. The count assertion does not
