# E03/E04 三轮逐项诊断

5个主PLY × D3D12/投影128/投影256/投影+排序128/投影+排序256 × 3轮，共75次、9000个测量帧。60帧预热/120帧采样、固定fit、1920×1080、完整原始点数/SH；逆序轮次、运行时快照及起止SHA校验。CUDA events开启，包含其计时开销，属于诊断；未达到正式30s/60s时长，也不代表Present帧率。

全部60张候选图像均通过RGB/alpha既定门槛，最大逐通道差为3/255；每轮PNG、指标和原始帧数据均保留。汇总见[SUMMARY.md](SUMMARY.md)、analysis.json。

结论：当前CUDA投影慢于HLSL。最大场景HLSL投影约10.5ms，CUDA128约13.8ms、256约13.0ms；CUB约2.37ms。组合后的完整GPU帧较D3D12降低6.49%/8.90%，但弱于E02单独排序14.21%；其他主场景没有达到5%的收益。256线程优于128，仍不能成为默认生产后端。保留参考实现作为后续tile输入/数学对照，继续单独验证数学、压缩和合成路径，不把组合堆叠视为自动有效。

内存：大模型D3D12的DXGI local usage约6.14GiB，共享输入/输出导入后约12.45GiB，超过DXGI当前budget；额外物理分配和共享映射计费必须区分。因此追加了相邻memory-d3d12/memory-cuda诊断。独立nvidia-smi全局峰值分别8313/8510MiB，未出现额外整份SH的物理副本。DXGI计费增加不能当作真实物理翻倍，也不能在生产准入时静默忽略；共享映射预算策略仍是待解决接入门槛。本组性能数据不能直接证明资源验收通过。
