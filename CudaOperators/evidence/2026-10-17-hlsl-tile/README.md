# E07/E08 and ordinary Graph validation

CUDA/HLSL use identical CUDA-generated tile lists, global ranks, 40-byte ellipses, 512-reference batches and analytic pixel-center inversion. HLSL initially failed compilation at 1024×40 bytes because groupshared exceeded 32KiB; both sides changed to 512. The original build log is retained. HLSL prepares Dispatch commands/counts on GPU and records bounded ExecuteIndirect calls with UAV barriers between batches; all submission and texture blit costs remain in the frame span.

Latest CUDA CTest: 8/8 passed, 56.63 seconds (`ctest-latest.log`). This covers toolchain, interop, isolated lifecycle, sort, projection, compaction and tile groups. CPU image oracle covers 1301 layers, 33×19 edge pixels, 8/16 tiles, full/empty/full reuse, back-to-front FP32/UNORM, front-to-back threshold 0/1e-5/1e-4 and ordinary Graph. Repeated tile memcheck: three repeats, zero errors (`early-graph-memcheck.log`). CUB Graph changing-input replay and changed binding/count/context/capacity rejection: two tests, zero memcheck errors (`sort-graph-memcheck-complete.log`). The first negative-test build used Windows' reserved macro `small`; it was renamed `undersized`, and the corrected build passed. Both logs remain.

Real-scene evidence is in adjacent `2026-10-17-hlsl-tile-image-diagnostic`, `2026-10-17-tile-image-medium` and `2026-10-17-tile-early-graph-diagnostic` directories. The last contains 16 one-round diagnostic runs, not formal performance acceptance. changjin CUDA/HLSL tile frame spans are about 7.75/7.31ms versus native 0.44ms. shengyi is about 33.20/31.17ms versus native 1.27ms. Ordinary Graph reduces tile submission overhead but cannot recover the native gap. Threshold variants also remain much slower.

**Rejected as an equal-quality/product path:** shengyi and tumu fail the unchanged maximum RGB/alpha error gates, despite SSIM/RMSE passing. HLSL reproduces CUDA's error, and an independent CPU calculation reproduces the CUDA UNORM pixel exactly. Thin-quad subpixel rasterization/interpolation is supported by the investigation but not completely reproduced. See [quality-investigation.md](quality-investigation.md). No blur, truncation, dropped splats, threshold relaxation or baseline modification was used. Contribution-count instrumentation remains unimplemented; E08 is not marked complete.

Conditional-while is a separate unresolved stability failure; these passes apply to ordinary bounded kernels/ordinary Graph only. This directory contains experimental infrastructure, not a renderer/SDK integration or a production stability claim.
