# Windows 自适应排序实施与验证

2026-10-28 用户授权逐项优化、短测试、撤回失败实验与产品接入。更新旧 W15 的统一收益准入：改为按规模选择；旧正式测试和长稳门槛不记为通过。

1. 冻结当前基线：17 万、80 万、125 万、391 万，60 帧预热/120 帧采样、两轮交替。
2. 分别测试 consumer 提前录制、批量屏障、producer 冗余完成信号，保留图像一致且有完整帧收益的组合。
3. 比较 CUB Graph、i32 和小规模专用稳定归并排序（对“简并排序”的实验解释），不截断键、不减少点、不降低 SH。
4. 实测决定保守阈值；实际 DX12 设备 LUID 匹配探测 CUDA；DLL 缺失、不支持、分配失败回退 DX12。
5. 私有版本化 C ABI 延迟加载；SDK 无 CUDA 链接依赖；共享映射/scratch/graph 按场景创建。保持静态复用、测距、换模、恢复。
6. RenderStats 区分设备可用性和已激活场景实际加速；GUI 角落仅后者显示“已启用 CUDA 加速”。
7. 构建及排序/图像/能力/回退/切换/清空/恢复/SDK 验证，记录未覆盖长稳与其他显卡。

GPU 实验串行，不启动其他代理，不提交或推送。

完成记录：162 次实验运行（158 次有效计时），全部图像与各自 DX12 参考字节一致。保留 CUB Graph 与 200 万点保守阈值；撤回提前录制、批量屏障、去冗余信号、组合交接、整段 Graph 和本轮稳定并行归并实现。真正独立的数据帧槽/重叠执行及全新 DX12 排序未实现，不将其列为性能失败。

完整 CTest 14/14 组通过；最终产品配置 CUDA 集成 5/5 执行且无跳过；缺 DLL 回退与真实 GUI 小/大模型加载、渲染、正常关闭通过。GUI 只核对状态日志，没有自动截图检验。旧两小时长稳与跨显卡矩阵仍未覆盖。详见[报告](../../docs/windows-cuda-adaptive-sort-2026-10-28.md)和[证据索引](../evidence/2026-10-28-adaptive-sort/README.md)。
