# Spec: instances-cache-v3

## Scope and dependencies
Extend the existing image-frame/render-worker/service-gateway/windows-client/linux-deployment modules. Implement in this order: spatial contract → native pinned instance → Go service and SQLite cache → Windows sessions/prefetch → deployment and verification. The user requested implementation and remote deployment; no additional approval gate is introduced.

## Spatial contract
Image packets remain NGSFRM02. New requests: `NGSREQ3 id model width height yaw pitch distance_factor profile flip_y`, where flip_y is 0 or 1. Legacy NGSREQ2 remains accepted with its original ±89° pitch validation. NGSREQ3 permits full-circle pitch/yaw within ±36000°. World basis is unchanged: Y up, yaw zero at +Z, positive yaw towards +X; orbit center is the existing normalized bounding center, never recomputed by flipping Y. Full spherical position is azimuth 0..358°/2 and colatitude 0..180°/2. At poles azimuth is retained to fix camera orientation. Crossing a pole folds position into this range and reverses camera roll. Flip Y reverses camera up/right (180° roll), not geometry or reference axes.

Distance uses 81 logarithmic bins, factor `10^((index-40)/40)`, indices 0..80 (0.1..10), fit at index40. Nearest rounding uses floor(value+0.5); angles wrap. Code is `aNNN-tNN-dNN`; image variant adds `f0/f1`, dimensions and codec. Cache namespace includes SHA256(model bytes) and renderer/grid revision, so model replacement or pipeline changes cannot reuse obsolete pixels. Requests at the same position share packets regardless of request/session identity; response headers are generated per request.

## Instance and concurrency contract
One loaded native process/renderer per model revision, assigned to one configured GPU for its lifetime. Default devices=0; multiple devices require explicit `--enable-multi-gpu`. Same-model clients share the instance and identical in-flight requests share one render. A GPU semaphore limits renders across instances; foreground has priority over speculative work. Max4 resident instances by default; admission failure is503, never silently evicts an active model. Idle instance TTL5min configurable. Model leases heartbeat every10s, expire after120s; explicit close releases immediately. Cache hits do not require loading a missing instance, but update foreground activity of an already loaded one. Prefetch never renews existing model/session activity. A live authenticated lease may start a missing instance for prediction after a foreground disk-cache hit; the foreground response itself still does not require GPU loading.

Go net/http manages the public endpoint, authenticated sessions, bounded requests/queues, subprocess ownership, graceful signal shutdown and deadlines. C++ only binds loopback. SQLite via the system libsqlite3 (cgo; no third-party Go module) stores versioned cache metadata, last user hit, size, digest and sessions. GPU/process state is runtime state, reconstructed after restart, not trusted from a stale database row. SQLite WAL with busy timeout; prepared/bound SQL. Cache file writes are atomic, indexed only after commit. Corrupt/missing packets are invalidated and rendered again. Delete entries 24h without a user hit; additionally bound total disk to10GiB with LRU eviction. Cache misses are coalesced. Startup removes abandoned temporary/orphan packets. Time-based retention uses UTC wall time, request performance uses monotonic time.

## HTTP contract and budgets
Keep /health (public, protocol2 plus api_version3), authenticated /models, /status and POST /frame. Sessions: POST /sessions body model id → JSON session_id; POST /sessions/heartbeat and /sessions/close body session id. Optional X-GS-Session validates model ownership on /frame. X-GS-Prefetch:1 marks speculative requests; it cannot extend TTL. Return X-GS-View-Code, X-GS-Cache(hit/miss/shared), identity and stats. Per-user lease caps and global connection/request/cache budgets must bound memory/disk. Default shared bearer token is administrative authentication, not multi-tenant user identity; sessions isolate views, not access control among different tenants. TLS mandatory unless explicit trusted-private HTTP.

## Client prefetch
Foreground remains single-flight/latest-wins. After displaying current frame, download four cardinal directions ×5 bins (configurable5/10/15) at same distance/resolution/profile/roll. Store compressed validated packets in a bounded64MiB client LRU; decode only when shown. One speculative download at a time, distinct from foreground; old generation stops remaining downloads. Move the prediction window on every move, reuse overlap, request only missing keys. Close/model switch/reconnect cancels pending work and releases leases. UI exposes Flip Y and pre-render enable/low-medium-high controls, reports local/server cache activity. Heartbeat keeps a still-viewed model active, including when every move is a client-local hit.

## Commands and verification
Linux: `cd ForServer/gateway && CGO_ENABLED=1 go test -race ./... && go vet ./... && go build -o gs-gateway .`. Native and Windows: existing CTest/build.ps1. Deploy: existing deploy.sh extended with Go and SQLite checks, device0 by default, TTL/disk/instance config, supervisor executing Go binary. Test spatial wrap/poles/flip/distance parity, cache persistence/corruption/TTL/size, coalesced same-model multi-user requests, leases/idle teardown/reload, cancellation/priority, actual GPU0-only process residency and real WinUI cached navigation. Remote deployment retains bearer auth/private HTTP from the authorized test installation; it does not imply unverified public TLS or tenant RBAC is production-ready.
SQLite/cache durability: frames and last-hit metadata are reconstructible. WAL synchronous=NORMAL and write-close-atomic-rename avoid fsync on every image/hit. Normal process restart preserves packets; abrupt host power loss may drop recent cache entries, which are safely invalidated/recomputed. This is not the storage policy for credentials/configuration or authoritative business records.
