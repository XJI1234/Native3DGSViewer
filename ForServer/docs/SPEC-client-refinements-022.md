# Cloud Windows 0.2.2：交互、预渲染与会话修订

用户授权实现、OCR审查、commit/push/merge和补充已有v0.2.2 Release。沿用API v3和NGSFRM02，独立安装包命名Native3DGSCloudViewer-0.2.2-Windows-x64-Setup.exe，不移动既有tag或替换本地查看器安装包。

拖动按屏幕位移操作模型：正常朝向反转原水平yaw输入，倒置后反转垂直pitch输入；水平同时考虑规范化球坐标穿极点的roll，世界球坐标基准不变。方向按钮/键盘与相同屏幕位移一致。测试正常/倒置/穿极点及非有限输入。

客户端默认JPEG85。预渲染低/中/高为每方向5/10/15档，默认低，共20/40/60位置；只后台下载缺失压缩包，不预先解码。64MiB/256项预算保留；完全关闭显式清空内存缓存，不创建持久下载目录。退出后的异步结果不得重新入缓存。

会话默认期限120秒、10秒心跳。控制HTTP使用短超时，与200秒图像传输期限分离；瞬时网络/可恢复HTTP失败有限重试，单次失败不宣布连接失效。410通过结构化HTTP状态恢复租约并刷新缓存；连续3次且30秒未成功才提示持续失败。恢复后清提示；旧模型/连接会话结果不得污染当前状态。后端/supervisor保留租约策略，实际静置超过旧30秒期限及服务器会话失效必须验证。

GoogleTest覆盖输入、5/10/15范围、缓存清除、心跳失败阈值与恢复。真实WinUI测试四画质、倒置和本地命中；增加静置/租约恢复和关闭缓存记录。Linux CTest/Go race/vet仍为部署门禁。OCR检查整个新增云端模块及本轮改动，处理有效问题后提交。

安装包为独立Inno Setup每用户产品；携带自包含WinUI、MSVC runtime及许可，验证silent install/installed-app smoke/uninstall；不嵌入地址凭据、模型或日志。README提供下载、操作、Linux部署及与原本地引擎的区别。发布说明记录附加源码commit，不能声称原tag源码含后来补充的cloud模块。
